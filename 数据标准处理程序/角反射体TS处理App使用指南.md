# 角反射体 TS 处理 App 快速上手

在 MATLAB 中打开 [corner_ts_app.m](./corner_ts_app.m)，点击 **运行**。

1. **选择数据。** 点击 **选择采集文件夹**，选中直接存放 JSON 和 MAT 的日期文件夹；若有多个通道，选择本次要处理的通道。
2. **滤波。** 填好频带，点击 **带通滤波**。如果回波位置不好辨认，可再做 **匹配滤波** 辅助定位。计算 TS 用的是带通波形。
3. **选窗。** 在热图上用横轴选首、末脉冲，用纵轴分别选直达波和回波的起止时间，每个窗点两次。也可以直接在左侧填数值。再填本次扫描的实际首末角度，例如 0°～40°。
4. **设置参考。** 填入发射换能器到目标的距离 L、水听器到目标的距离 r（米）。常规处理选 **逐脉冲直达波参考**；分置处理选 **固定脉冲直达波参考**，填写参考脉冲的原始编号，并在该脉冲的波形上核对直达波窗。
5. **计算 TS。** 先点 **计算单频 TS** 查看指定频点的角度曲线。需要频率–角度谱或整套图表时，填好扫频范围和间隔，再点 **计算全频段 TS**。
6. **保存。** 只要当前图，点 **导出当前图 PNG + FIG**；全频段计算完成后，点 **导出全部图表与数据**，选择保存位置，即可得到图、MAT 和 CSV。

**色阶保存：** 在 App 内拖动颜色条后松开鼠标，或输入上下限并点 **应用并锁定**，导出的热图会采用调整后的范围。

**去除固定横带（可选）。** 完成带通滤波后，设好扫描首末脉冲（至少两次），选择 **点两次选背景窗**，在图上点出横带的上下边界，再点 **脉冲维去零频**。程序只在该选区逐行减去脉冲均值。锁定波形色阶后，可在 **带通波形** 和 **脉冲维去背景** 之间切换对照；改动背景窗或扫描范围后需重新去零频。去背景图用于选窗，可从图右上角保存。TS 仍取原带通数据计算。
