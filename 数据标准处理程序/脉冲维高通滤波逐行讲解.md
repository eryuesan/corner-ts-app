# 脉冲维高通滤波：逐行读懂 pulseHighpass

对应 v2 的 [corner_ts_app.m](./corner_ts_app.m) 第 909–924 行。选定一条横带后，矩阵 `block` 的每一行对应一个采样时刻，每一列对应一次脉冲。比如只看 5.500 ms 这一行，沿行从左往右读，就是同一时刻的带通波形值随脉冲编号的变化。这里的频率单位是**周期/脉冲**。

## 固定横带为什么会在零频处形成高峰？

取某一行的实际数据 `x`，长度为 `n`。代码先把它镜像拼成长度为 `2*n` 的一行，再调用 MATLAB 默认的、未经归一化的 FFT。第一个系数就是零频系数：

```matlab
extended = [x fliplr(x)];
X = fft(extended);
X(1) = sum(extended);     % 数学关系：等于 2*n*mean(x)
```

所以，**如果固定回波在这个采样时刻形成了稳定、明显的非零均值，零频幅值就会很大**。例如 200 次脉冲在该时刻都是 0.8 V，镜像后有 400 个值，零频系数为 320，其余频点为零。要还原平均电压，用 320 除以 400，得到 0.8 V。若这一行均值为 −0.8 V，零频系数是 −320，幅值依然是 320。

还要看你画的是哪种数据。热图颜色通常表示幅值的分贝，而这里做 FFT 的是**带正负号的波形值**。假如某一行是 `[0.8, -0.8, 0.8, -0.8]`，热图上四点同样亮，但均值为零，零频系数也为零。因此，横带很亮不一定意味着零频峰很高；要看同一采样时刻的波形值在各次脉冲间是否同号、稳定。

## 源码与行号

```matlab
function filtered = pulseHighpass(block,fc)
% 沿每行的脉冲序列作偶对称延拓，再施加二阶巴特沃斯形状的零相位幅频响应。
n = size(block,2);
bins = 0:2*n-1;
f = min(bins,2*n-bins)/(2*n); % 周期/脉冲，正负频率取相同增益
gain = zeros(size(f));
gain(2:end) = 1./sqrt(1+(fc./f(2:end)).^4);
filtered = zeros(size(block),'like',block);
for startRow = 1:64:size(block,1)
    rows = startRow:min(startRow+63,size(block,1));
    data = block(rows,:);
    extended = [data fliplr(data)];
    y = ifft(fft(extended,[],2).*gain,[],2,'symmetric');
    filtered(rows,:) = y(:,1:n);
end
end
```

| 行号 | 这一行做了什么 |
|---|---|
| 909 | 接收选中的矩形 `block` 和截止频率 `fc`，返回与选区大小相同的矩阵 `filtered`。 |
| 910 | 注释说明处理方法：先做镜像延拓，再按二阶巴特沃斯高通曲线调整频谱幅值。增益实数且非负，各频率成分不会被额外移相。 |
| 911 | `size(block,2)` 取列数，即所选脉冲数。例如第 101～300 次脉冲对应 `n=200`。 |
| 912 | 给延拓后的 FFT 频点编号，从 0 到 `2*n-1`，共 `2*n` 个。 |
| 913 | 把编号换成频率的绝对值。若 `n=4`，八个值依次是 0、0.125、0.25、0.375、0.5、0.375、0.25、0.125。后半段对应负频率，取绝对值让正负频率得到同样的增益。 |
| 914 | 建立增益数组，初值全为零。MATLAB 从 1 开始编号，`gain(1)` 对应零频。 |
| 915 | 只给第 2 个至末尾频点赋值，零频增益因此保持为零。非零频率越低，保留的幅值比例越小。 |
| 916 | 预先分配输出矩阵，尺寸和数值类型与输入一致。 |
| 917 | 每批处理最多 64 个采样时刻，限制临时数组占用的内存。每一行仍然使用全部选中的脉冲。 |
| 918 | 算出本批的行号。最后一批即使不足 64 行，也只取到矩阵末尾。 |
| 919 | `block(rows,:)` 取出本批的行，冒号表示取所有脉冲列。 |
| 920 | 把每一行左右翻转后接到右边。例如 `[2 3 5 8]` 变为 `[2 3 5 8 8 5 3 2]`。FFT 将输入视作周期重复，镜像使首尾衔接时不会从 8 突然跳到 2，能减轻边缘伪影。 |
| 921 | 沿第 2 维做 FFT，各频点乘各自的增益，再沿第 2 维做逆 FFT。下方把这一行拆成三步。 |
| 922 | 取回前 `n` 列，即实际采集的脉冲，写入本批对应的输出行。 |
| 923 | 结束分批循环。 |

## 第 921 行里的 .*gain 究竟乘了什么？

```matlab
X = fft(extended,[],2);              % 固定采样时刻，沿脉冲轴分解频率
Xfiltered = X .* gain;               % 每个频点乘它自己的幅值保留比例
y = ifft(Xfiltered,[],2,'symmetric'); % 沿同一维度还原为实数波形
```

`.*` 在 MATLAB 里是逐元素相乘。`gain` 是一个行向量，同一套权重用于每个采样时刻。例如频谱系数为 `3+4i`，对应增益为 0.2，相乘得到 `0.6+0.8i`，幅值由 5 降为 1，相位保持不变。零频系数即使是 320，乘以 `gain(1)=0` 后也会消失。

第 915 行决定每个频点的增益。以默认截止频率 **0.01 周期/脉冲**为例：

| 跨脉冲的变化 | 频率（周期/脉冲） | 幅值保留比例 |
|---|---:|---:|
| 恒定 | 0 | 0% |
| 每 200 次脉冲一轮 | 0.005 | 约 24% |
| 每 100 次脉冲一轮 | 0.01 | 约 71% |
| 每 50 次脉冲一轮 | 0.02 | 约 97% |

这些比例描述单个频率成分。真实回波包含多种成分，固定背景和缓慢变化的目标成分都可能衰减。在 App 中锁定同一色阶，对照处理前后目标轨迹穿过横带的那一段，可以直接观察这种取舍。
